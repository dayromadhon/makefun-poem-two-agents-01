"Two Hands on One Wheel" is a four-line poem about two agents who arrive at a fork in the road, weigh the cost of going separate ways, and agree to take the same road together, because two hands on one wheel steer straighter.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the poem to `out/entry.txt` — exactly 198 Unicode code points of UTF-8, with no trailing newline.
